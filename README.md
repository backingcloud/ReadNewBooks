# 未读之书 · 便携文件夹版

## 首次使用

1. 把整个「未读之书」文件夹复制到一台可写入的 Windows 电脑上。若希望本机资料保存在 D 盘，请把文件夹放在 D 盘。
2. 将 `secrets.env.example` 复制一份并命名为 `secrets.env`，由使用者自行填写微信读书与 DeepSeek API Key。请勿把填过密钥的文件发送给其他人。
3. 双击 `启动未读之书.bat`。程序优先使用包内 Python；若包内运行环境缺失，则检查 Python 3.11/3.12，并在找不到时提示安装。

## 采集后的保存方式

- **仅本次查看**：书籍资料和 AI 解读只保留在当前工作台内存；退出工作台程序后无法从本机重新打开。运行日志、缓存和临时文件仍保存在程序文件夹内，不包含 API Key。
- **保存到本地**：默认写入便携包内的 `data/library`，也可在页面中输入路径或使用“选择文件夹”更改；自定义目录须位于程序文件夹内，复制整个文件夹时资料可一起移动。选择“保存到本地”后，页面会自动滚动并突出提示保存位置。再次搜索同一本书时，会在所选目录中查找并打开已保存资料，不必重新采集；想更新时再主动选择重新采集。

与书对话会在当前浏览器会话中按书籍保留全部问答，不重复发送历史问题；关闭会话后清除。自动生成 AI 解读会把实际使用的书评和划线样本发送给 DeepSeek，可能产生费用，单次预算上限为 ¥0.50。是否保存在本地与是否发送模型是不同的事情。

## 运行说明

- 若端口被占用，程序会自动尝试 8765–8784；实际工作台地址会显示在启动窗口。启动窗口会保持打开，日志保存在 `runtime/logs/reading-desk.log`。
- 需要联网访问微信读书与 DeepSeek。
- 程序数据、Python 运行环境、日志、缓存和临时文件都跟随便携文件夹，不依赖原电脑的用户目录或固定安装位置。
- 请复制整个文件夹，不要只复制启动脚本。
